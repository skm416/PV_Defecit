# PV Yield Deficit Analysis - Delhi (2020–2023)

This Jupyter notebook quantifies the energy yield deficit in rooftop PV systems due to atmospheric attenuation (clouds, aerosols, etc.) in Delhi.

## What the notebook does

- Simulates AC power output under clear-sky and actual irradiance conditions
- Compares actual vs. modeled performance
- Calculates energy yield deficit (absolute and percentage)
- Computes economic cost of the lost generation using Delhi electricity tariff
